# Government Fraud Detection — MLOps

End-to-end machine learning operations project

## Project Objective

Design and implement a fraud-detection system for a fictional government agency processing financial assistance applications.

The system will provide fraud probability estimates through a RESTful API and support experiment tracking, monitoring, data drift detection, and automated model retraining and redeployment.

The project uses synthetic application data and runs locally, with cloud deployment considered an optional extension.

## Technology Stack

- Python
- pandas and NumPy
- scikit-learn
- FastAPI
- MLflow
- GitHub Actions
